# Quick Start

1. Download the EXE from the official GitHub Release.
2. Open Tender PDF Compiler.
3. Add one or more Bid Response PDFs.
4. Leave **Include original Bid Response PDF** unchecked for the compact compilation, or check it if you want the complete source PDF included.
5. Start processing.
6. Review the generated PDF and CSV report.
7. Investigate any `CHECK`, attachment or failed-download status before relying on the compilation.

Always verify important procurement records against the original source documents.
