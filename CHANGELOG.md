# Changelog

## v1.0.0 - Initial public release

Planned release features:

- Batch processing of Bid Response PDFs.
- Automatic extraction of listed document download links.
- Organized compiled PDF with table of contents, covers and bookmarks.
- Optional inclusion of the original Bid Response PDF.
- Blank-document warning (`CHECK`) without deleting the retrieved file.
- Correct saving of non-PDF attachments.
- Permanent CSV batch report.
- Cleaner source-link presentation on generated covers.
- Sequential downloading and retry/skip/stop handling.
- Application version shown in the interface and generated output.

### Deferred

- Duplicate-content warning.
- Dynamic adaptation to future e-GP table-layout changes.
- Parallel downloading.
- OCR and automatic document classification.
- Bid evaluation/compliance decisions.
