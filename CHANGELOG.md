# Changelog

## v1.0.0

Initial public release.

### Features

- Batch processing of Bid Response PDFs.
- Automatic extraction of listed document download links.
- Organized compiled PDF with table of contents, covers and bookmarks.
- Optional inclusion of the original Bid Response PDF.
- Blank-document warning for retrieved PDFs that appear essentially blank.
- Separate saving of non-PDF attachments.
- Permanent CSV batch report.
- Cleaner source-link presentation on generated covers.
- Sequential downloading with retry/skip/stop handling.
- Version information in the application and generated output.
