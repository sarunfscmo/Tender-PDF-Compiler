# Security

## Official downloads

Use only the official GitHub Release published by this repository. Each public release should include a SHA-256 checksum.

## Windows warnings

Unsigned or newly published executables may trigger Microsoft Defender SmartScreen or antivirus reputation warnings. Verify that the file came from the official release and compare its SHA-256 checksum.

## Reporting

If you find a security issue, do not post sensitive bid information in a public GitHub issue. Contact the project maintainer privately using the contact method published on the repository profile/release page.

## Sensitive information

Never upload real bid-response documents, bidder records, credentials, account data or confidential procurement material to this public demo repository.
