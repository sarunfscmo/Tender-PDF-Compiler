# Synthetic Tender Demo Files

These files are **not real procurement records**. They were created only for the
Tender PDF Compiler public demonstration.

- No real bidder name.
- No real public-office name.
- No real bank.
- No real PAN/VAT number.
- No real address or signature.
- No real project or contract.
- Financial values are synthetic.

The documents intentionally vary in appearance and length so the compiled
output is visibly useful in a tutorial.

`02_Blank_Voucher.pdf` is intentionally a completely blank one-page PDF. It is
used to demonstrate the application's blank-document warning and should not be
"fixed" before recording the demo.

See `demo_manifest.csv` for the intended e-GP-style display names, document
types, page counts and raw GitHub URL templates.
