# Privacy

Tender PDF Compiler is designed as a local desktop utility.

## Data handled locally

The program may read:
- Bid Response PDFs selected by the user;
- hyperlinks and document metadata contained in those PDFs; and
- downloaded documents needed to create the compilation.

Generated PDFs, attachment folders and CSV reports are saved locally.

## Network activity

The application makes network requests to the document URLs contained in the selected Bid Response PDF. Demo material may instead point to files hosted in this GitHub repository.

The application does not require a Tender PDF Compiler account and does not send selected bid documents to a developer-operated server.

## No analytics

v1.0.0 does not include developer analytics, advertising telemetry or a developer tracking service.

## User responsibility

Users should process only documents they are authorized to access and should follow the applicable procurement, records-management and information-security requirements of their organization.
