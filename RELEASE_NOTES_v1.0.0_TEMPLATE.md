# Tender PDF Compiler v1.0.0

Initial public release.

## Highlights

- Compile linked tender documents into one navigable PDF.
- Batch-process multiple Bid Response PDFs.
- Optional inclusion of the original Bid Response document.
- Blank-document warning.
- Separate handling of non-PDF attachments.
- CSV processing report.
- Cleaner cover sheets and navigation.

## Download

Download `TenderPDFCompiler-v1.0.0-Windows.exe` from the assets below.

Also download the matching `.sha256.txt` file if you want to verify the binary.

## Important

This is an independent document-organization utility. It does not log in to,
submit to, or modify Nepal e-GP, and it does not make procurement decisions.

Tested target: Windows 10/11 64-bit.

## Demo

The repository contains synthetic demo documents only. No real bidder or
procurement information is included.
